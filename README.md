# Linux Server Monitoring Tool

A simple bash script to monitor Linux server health - CPU, Memory, Disk

## Features
- Check CPU Usage
- Check Memory Usage (free -h)
- Check Disk Usage (df -h)
- Check Top 5 Memory Consuming Processes
- Threshold Based Alerts (CPU > 80%)
- Intermediate Level Automation

## How to Use
```bash
chmod +x server_monitor.sh
./server_monitor.sh
```
